# Contributing

EleitorUM is an archived project. It was built to solve a specific, bounded problem and ships as a single version (v1.0.0).

**External contributions are not accepted.** Pull requests will not be reviewed or merged. Issues may be filed for documentation purposes but will not be acted upon.

If you need a similar tool adapted for a different context, please fork the repository and adapt it independently.
