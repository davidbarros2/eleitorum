    ```
    sys.path.insert(0, os.path.join(os.path.dirname(__file__), "..", "src"))
    from eleitorum.version import __version__
    ```

    Helper function `_generate_version_info(version: str) -> None`:
    Parses version string into a 4-tuple (append zeros if needed). Writes `version_info.py` to the current directory (repo root, where build is run from) containing a `VSVersionInfo(...)` literal. The content must be a valid PyInstaller version file. Fields: `CompanyName = ""`, `FileDescription = "EleitorUM — Normalizador de ficheiros eleitorais"`, `FileVersion = "{major}.{minor}.{patch}.{build}"`, `InternalName = "EleitorUM"`, `LegalCopyright = "MIT License"`, `OriginalFilename = "EleitorUM.exe"`, `ProductName = "EleitorUM"`, `ProductVersion = "{major}.{minor}.{patch}.{build}"`. Translation: `[1033, 1200]`. Use `textwrap.dedent` to produce clean indentation in the output file. Write with `encoding="utf-8"`.

    Helper function `_create_zip(version: str) -> pathlib.Path`:
    Constructs `zip_name = f"EleitorUM-{version}-win64.zip"`. Creates the ZIP in the current directory using `zipfile.ZIP_DEFLATED`. Iterates `pathlib.Path("dist/EleitorUM").rglob("*")`; for each file `f`, adds it as `f.relative_to("dist")` so the zip contains `EleitorUM/EleitorUM.exe` etc. Prints each added path at verbosity level. Returns the zip path.

    Helper function `_write_sha256(zip_path: pathlib.Path) -> None`:
    Reads the zip with `.read_bytes()`, computes `hashlib.sha256(...).hexdigest()`. Writes `f"{digest}  {zip_path.name}\n"` (BSD-style, two spaces between digest and filename) to `zip_path.with_suffix(".zip.sha256")` with `encoding="utf-8"`. Prints the digest to stdout.

    Main function `main() -> None`:
    - Parse `--onefile` flag via argparse (add_help=True for developer use; this is not the user-facing CLI)
    - Print `f"Building EleitorUM {__version__}..."`
    - Call `_generate_version_info(__version__)`
    - Build the PyInstaller argument list. Base args: `["src/eleitorum/__main__.py", "--name=EleitorUM", "--windowed", "--icon=src/eleitorum/resources/icons/EleitorUM.ico", f"--version-file=version_info.py", "--add-data=src/eleitorum/resources/fonts/Inter:resources/fonts/Inter", "--clean", "--noconfirm"]`. Add `"--onedir"` or `"--onefile"` based on the parsed flag (default: `--onedir`). Add comment in source (not in the list — as a code comment above the list): `# --onefile: manual opt-in; results in slower cold start and Windows Defender scan on each launch (D-07)`.
    - Import and call `PyInstaller.__main__.run(args)` (import inside main() to avoid loading PyInstaller on --help)
    - Call `_create_zip(__version__)`
    - Call `_write_sha256(zip_path)`
    - Print `"Build complete."` with the zip filename

    `if __name__ == "__main__": main()` at the bottom.

    Do NOT run the build script as part of this task — only create the file. The script will be run in CI; a local trial run is optional and not part of verification.
