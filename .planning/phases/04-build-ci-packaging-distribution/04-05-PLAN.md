    6. `name: Smoke test — --version`
       PowerShell multi-line run block:
       ```
       $output = & dist\EleitorUM\EleitorUM.exe --version 2>&1

         Write-Error "EleitorUM.exe --version exited $LASTEXITCODE"
         exit 1
       }
       if ($output -notmatch "EleitorUM 1\.0\.0") {
         Write-Error "Version mismatch: $output"
         exit 1

       Write-Host "Smoke test passed: $output"
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions → GITHUB_TOKEN | Auto-injected secret; used only by softprops/action-gh-release to attach files to a tag release |
| Smoke test → EleitorUM.exe | EXE is the output of the build step in the same workflow; no user-controlled input to the EXE |
| pip install in CI → PyPI | Pinned versions in pyproject.toml; pip-audit job catches newly published CVEs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05-01 | Tampering | GITHUB_TOKEN scope | accept | Token is scoped to the repo by GitHub; used only for release upload; no write access to other repos |
| T-04-05-02 | Tampering | Supply chain via pip in CI | mitigate | All packages pinned in pyproject.toml; pip-audit CI job scans for CVEs on every push |
| T-04-05-03 | Denial of Service | CI cost overrun | accept | windows-latest is free for public repos (CI-05); no paid runners; no concurrency limits relevant at this scale |
| T-04-05-04 | Information Disclosure | Release artifacts publicly attached | accept | Artifact is the intended public distribution; no credentials or personal data in the ZIP |
| T-04-05-SC | Tampering | softprops/action-gh-release@v2 | mitigate | Pinned to @v2 (semantic tag); widely used action from trusted source; RESEARCH.md Package Legitimacy Audit reviewed |
</threat_model>
