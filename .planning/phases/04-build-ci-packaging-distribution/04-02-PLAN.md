    Imports in ruff order (stdlib first, then third-party):
    - stdlib: `import io`, `import os`, `import pathlib`, `import sys`
    - third-party: `from PIL import Image`, `from reportlab.graphics import renderPM`, `from svglib.svglib import svg2rlg`

    Constants:
    - `SVG_PATH: pathlib.Path = pathlib.Path("src/eleitorum/resources/icon.svg")`
    - `OUT_DIR: pathlib.Path = pathlib.Path("src/eleitorum/resources/icons")`
    - `SIZES: list[int] = [16, 32, 48, 64, 128, 256, 512]`
    - `ICO_SIZES: list[int] = [16, 32, 48, 64, 128, 256]` (max 256 per standard ICO spec)

    Main function `generate() -> None`:
    - Check that SVG_PATH exists; if not, print error and sys.exit(1)
    - Create OUT_DIR via `OUT_DIR.mkdir(parents=True, exist_ok=True)`
    - Call `svg2rlg(str(SVG_PATH))` — pass as string since svglib 1.6.0 requires str path
    - Check drawing is not None; if None, print error and sys.exit(1)
    - Render to PNG bytes via `renderPM.drawToFile(drawing, buf, fmt="PNG", dpi=96)` where buf is `io.BytesIO()`; seek(0)
    - Open with `Image.open(buf).convert("RGBA")` to get `img_full`
    - For each size in SIZES: resize with `img_full.resize((size, size), Image.LANCZOS)`, save to `OUT_DIR / f"EleitorUM-{size}.png"`, print `f"  {size}x{size} PNG"` to stdout
    - Build `ico_images` list: `[img_full.resize((s, s), Image.LANCZOS) for s in ICO_SIZES]`
    - Save ICO: `ico_images[0].save(str(OUT_DIR / "EleitorUM.ico"), format="ICO", sizes=[(s, s) for s in ICO_SIZES], append_images=ico_images[1:])`
    - Print `"  EleitorUM.ico (multi-size)"` to stdout

    `if __name__ == "__main__": generate()` guard at the bottom.

    After writing the file, run it from the repository root:
    `python scripts/generate_icons.py`

    The script must complete without errors. Verify that 8 output files exist (7 PNGs + 1 ICO).
