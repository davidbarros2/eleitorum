**Pattern 1 — Byte-exact CSV (output.py):**
```text
import csv
def write_csv(path, header, rows):
    with open(path, mode='w', encoding='utf-8-sig', newline='') as f:
        writer = csv.writer(
            f, delimiter=';', quoting=csv.QUOTE_NONE,
            escapechar='\\', lineterminator='\r\n',
        )
        writer.writerow(header)
        for row in rows:
            writer.writerow(row)
```
Verification: first 3 bytes are `\xef\xbb\xbf`; all line endings are `\r\n`; no quote chars appear.

**Pitfall 3:** `QUOTE_NONE` requires `escapechar` to be set (else `TypeError`). Always pair them.

**Pitfall 6 — F/D/B mixed-case collision:**
The validate.py uniqueness keys MUST be uppercase. transform.transform_mecanografico already returns uppercase prefixes, so the input to validate_rows always has uppercase prefixes — but write a test that explicitly passes a mixed-case raw input through transform_mecanografico and into validate_rows to confirm the F/D/B collision is detected.

**Log format example (Eleitorum.md Section 8.1) — must match byte-for-byte:**
```text
[2026-05-23 14:32:15] INICIO  Tipo de output: caderno eleitoral
[2026-05-23 14:32:15] INPUT   Ficheiro: cadernos_originais.xlsx
[2026-05-23 14:32:15] INPUT   Codificação detetada: UTF-8 com BOM (confiança 0.99)
[2026-05-23 14:32:15] CASO    Normalização de prefixos: minúsculas (215 minúsculas vs 32 maiúsculas)
[2026-05-23 14:32:16] LIMPEZA Linha 12: removido espaço inicial em "  Maria Santos"
```

Note: the tag field is left-padded to 7 chars (`{tag:<7}`). "INICIO" → 6 chars + 1 space pad = 7-wide field, then one space, then the message. "LIMPEZA" → already 7 chars, no pad, then one space, then message. Test cases must assert this exact width.

**Validation aggregation pattern (D-07):**
```text
def validate_rows(transformed, output_type):
    failures = []
    tracker = UniquenessTracker()
    for (row_idx, prefix, number, name) in transformed:
        # VAL-06 / VAL-07
        if not name:
            failures.append(FailureRow(row_idx, "nome", "(vazio)", "nome em branco após normalização"))
        # VAL-03/04/05: record uniqueness
        dup_failure = tracker.record(prefix, number, f"{prefix}{number}", name, row_idx)
        if dup_failure:
            failures.append(dup_failure)
    return ValidationOutcome(passed=not failures, failures=failures)
```

Critical: `tracker.record()` returns a FailureRow on collision but the loop CONTINUES — it does not break/raise. Every row is checked, every failure collected.
