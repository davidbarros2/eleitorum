```text
@dataclasses.dataclass
class PipelineSource:
    """How to interpret the input. Most fields are optional and only used for Excel multi-sheet
    inputs or pre-resolved manual column mappings."""
    path: pathlib.Path
    sheet_name: str | None = None          # for multi-sheet Excel; None = first sheet
    manual_mec_col: int | None = None      # override DET-03 auto-detection; None = auto-detect
    manual_name_col: int | None = None     # override DET-04 auto-detection
    csv_delimiter: str | None = None       # override CSV delimiter; None = auto (; for .csv, \t for .tsv)
    encoding: str | None = None            # override INP-07 detection (rare; for testing)

@dataclasses.dataclass
class PipelineResult:
    """Single return type for both success and failure."""
    success: bool
    output_path: pathlib.Path | None       # set on success
    log_path: pathlib.Path | None          # set on success
    error_log_path: pathlib.Path | None    # set on failure (instead of output + log)
    rows_processed: int
    transformations_applied: int
    detection: dict[str, Any]              # encoding, header_row_index, mec_col_index, name_col_index, detection_method
    failures: list[FailureRow]             # populated on failure
    log_entries: list[str]                 # the log lines built during the run (for the UI's "Ver detalhes" panel)

def run_pipeline(
    source: PipelineSource | pathlib.Path | str,    # accepts plain path for convenience
    output_type: Literal["caderno", "elegiveis"],
    output_path: pathlib.Path | None = None,         # if None, dry-run (validate only, no write)
    *,
    progress_cb: Callable[[int, int], None] | None = None,
    overwrite_allowed: bool = False,
) -> PipelineResult:
    """
    Main pipeline entry point. Qt-free.

    Args:
        source: file path or PipelineSource with options.
        output_type: 'caderno' or 'elegiveis'.
        output_path: destination CSV. If None, dry-run.
        progress_cb: called as progress_cb(current_row, total_rows). D-04 contract.
        overwrite_allowed: pass True only after explicit user consent (Phase 2 UI's responsibility).

    Returns PipelineResult — never raises EleitorumError; instead returns success=False with
    error_log_path populated. Genuinely unexpected exceptions (ImportError, MemoryError) DO
    propagate — pipeline only catches EleitorumError subclasses.
    """
```

**Pipeline execution sequence (the canonical order):**

```text
1. Normalize input: if source is path-like, wrap in PipelineSource(path=...).
2. Build LogBuilder; add INICIO line "Tipo de output: {output_type}" and INPUT line "Ficheiro: {source.path}".
3. Read input:
   - readers.read_input(source.path, sheet_name=source.sheet_name)
   - On FileAccessError or UnsupportedFormatError: caught, recorded as ERRO, error log written, PipelineResult(success=False).
4. For CSV/TSV: detect encoding from result.raw_bytes_sample (skip if source.encoding override given):
   - encoding_result = detection.detect_encoding(raw_bytes_sample)
   - Add INPUT line "Codificação detetada: {encoding} (chaos {raw_chaos} ou via BOM={via_bom})".
   - If EncodingDetectionError: caught, ERRO log, write error log, return failure.
5. Detect header row from result.rows:
   - header_row_index = detection.detect_header_row(result.rows)
   - If None: ColumnDetectionError raised by pipeline (or, if manual_mec_col + manual_name_col both supplied, skip detection and use those). For Phase 1: raise as failure; Phase 2 will eventually call run_pipeline again with manual overrides.
6. Detect columns from header_row + data_rows:
   - col_mapping = detection.detect_columns(header_row, data_rows, output_type)
   - If mec_col_index is None for caderno (auto-detect failed AND no manual override): ColumnDetectionError.
   - For ambiguous candidates: ColumnDetectionError naming the candidates (Phase 2 UI will resolve).
   - Add COLUNA lines describing the chosen mappings.
7. Transform every data row:
   - For row_index, raw_row in enumerate(data_rows, start=header_row_index+2):  # 1-based for user display
       - Extract mec_raw = raw_row[col_mapping.mec_col_index] (skip for elegiveis)
       - Extract name_raw = raw_row[col_mapping.name_col_index]
       - For caderno: transform_mecanografico(mec_raw, row_index) -> (prefix, number, changes); on MecanograficoError, accumulate FailureRow and CONTINUE (D-07 aggregation).
       - transform_name(name_raw, row_index) -> (name, changes)
       - Append all changes to log via LogBuilder.add_change.
       - If progress_cb: call progress_cb(row_index - header_row_index - 1, total_data_rows) every 100 rows AND on the last row.
8. Case normalization (caderno only):
   - normalize_mecanografico_case(transforms, raw_prefix_strings) -> (chosen_case, lower, upper, change_record)
   - Add the change_record to the log (CASO tag).
   - Apply chosen_case to every prefix when building output rows.
9. Validate:
   - validate.validate_rows(transformed_with_metadata, output_type) -> ValidationOutcome
   - If outcome.failures (collected during transform OR new from validate): write_error_log_file, return failure.
10. Validate output path (if output_path provided): validate.validate_output_path(source.path, output_path, overwrite_allowed). On OutputPathError: ERRO log, write error log, return failure.
11. Write output (if output_path provided):
    - For caderno: output.write_caderno(output_path, rows, input_path=source.path, overwrite_allowed=overwrite_allowed)
    - For elegiveis: output.write_elegiveis(output_path, designations, ...)
    - On FileAccessError: ERRO log, write error log, return failure.
12. Add SAIDA log line "Ficheiro gerado: {output_path} ({N} linhas)".
13. Add FIM line "Processamento concluido com sucesso. {N} alteracoes."
14. write_log_file(builder, output_path).
15. Return PipelineResult(success=True, output_path=..., log_path=..., rows_processed=N, transformations_applied=M, detection=..., failures=[], log_entries=builder.entries).
```

**D-07 hard-error path (steps 3, 4, 5, 6, 9, 10, 11 — any failure):**
- Build the error log file using the LogBuilder accumulated up to the failure point + the ERRO line + each FailureRow as its own ERRO line.
- Filename: write_error_log_file(builder, intended_output_path=output_path or source.path.with_suffix(".csv"))
- Return PipelineResult(success=False, error_log_path=..., output_path=None, log_path=None, failures=[...]).
- Never partially write the CSV (OUT-10).
