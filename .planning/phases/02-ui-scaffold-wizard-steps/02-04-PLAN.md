<objective>
Build the four upper-half wizard step widgets (steps 1, 2, 2.5, 3) that gather the user's input before processing: `StepType` (output type selection), `StepUpload` (file load via drag-and-drop OR file chooser), `StepSheet` (multi-sheet picker, shown conditionally), and `StepColumns` (column mapping with auto-detection + manual override). Each step receives a shared `SessionModel`, mutates its slice in place, and exposes `is_complete() -> bool` so the wizard's NavBar can enable/disable Próximo.

Purpose: Implement the four pre-processing steps as independent, parallel-developable widgets. Each step is self-contained, depends only on session/strings/theme + the three reusable widgets from plan 03, and ships with a pytest-qt smoke test that constructs the widget with a pre-populated SessionModel and asserts basic behavior.

Output: Four step widgets, one steps subpackage marker, four pytest-qt smoke tests, all green.
</objective>
