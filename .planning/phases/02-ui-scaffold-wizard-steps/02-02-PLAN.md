<objective>
Build the non-widget foundation of the Phase 2 UI: `SessionModel` (the @dataclass holding all wizard state, Qt-free), `strings.py` (all PT-PT user-facing strings centralized per APP-20), `theme.py` (LIGHT_QSS / DARK_QSS QSS strings + apply_theme + detect_system_theme), the branded SVG icon (BRAND-02), the Inter font directory placeholder with OFL.txt, and unit tests for session/theme/strings. These artifacts are consumed by every step widget in plans 03-06 and by main_window in plan 06.

Depends on plan 02-01 only for the `tests/unit/ui/__init__.py` and `tests/unit/ui/conftest.py` test-package scaffold (pytest discovers tests via package marker + conftest; without these from 02-01, this plan's new test files cannot be collected).

Purpose: Lock down the data contract (SessionModel), the visual contract (theme + icon), and the PT-PT string contract (strings.py) before any widget code is written. This eliminates churn in widget plans and guarantees APP-20 (no English UI strings shipped) is structurally enforced.

Output: Five Python modules + one SVG + one OFL.txt + three unit-test files, all importable without a running QApplication (except theme apply functions which require it).
</objective>
