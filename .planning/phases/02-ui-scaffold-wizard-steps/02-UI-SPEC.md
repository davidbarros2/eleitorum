# Phase 2 — UI Design Contract

> Visual and interaction contract for Phase 2: UI Scaffold + Wizard Steps.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> **Stack note:** This is a PySide6 desktop application. There is no web framework,
> no shadcn, no Tailwind. The design system is implemented as QSS string constants
> in `src/eleitorum/ui/theme.py`. All token values below map directly to QSS
> properties and `QFont` calls.

## Spacing Scale

Declared values (multiples of 4). All values applied as QSS `padding`, `margin`,
`spacing`, and `setContentsMargins()` / `setSpacing()` arguments.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gap, inline badge padding, table cell padding |
| sm | 8px | Compact element spacing, button internal vertical padding |
| md | 16px | Default element spacing, form row gaps, group box padding |
| lg | 24px | Wizard step content area padding, section breaks within a step |
| xl | 32px | Major section breaks, drop zone internal vertical padding |
| 2xl | 48px | Hero area vertical whitespace (step 1 option cards, step 6 result area) |
| 3xl | 64px | Not used — window minimum height (500px) limits large spacers |

Exceptions:
- Drop zone minimum height: 120px (usable drag target; not a spacing token)
- Step indicator label: 0 vertical margin (tight to header/footer edge)
- Footer button bar: 8px vertical padding, 8px gap between buttons
- NavBar Anterior/Próximo/Cancelar buttons: minimum width 100px (touch/click comfort)
- Window minimum size: 600 × 500 px; initial size: 900 × 650 px (APP-03, not spacing tokens)

## Typography

All sizes applied via `QFont.setPointSize()` or QSS `font-size`. Line height
is set via QSS `line-height` on QLabel where applicable; Qt does not support
per-widget line-height on all widgets, so body text in QLabel uses the default
Qt line spacing (approximately 1.2× at these sizes — acceptable for single-line
labels). Multi-line body copy (QTextEdit, QLabel with word-wrap) uses explicit
`line-height: 1.5`.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (Regular) | 1.5 | All descriptive text, wizard step body copy, column mapping labels, About dialog body |
| Label | 13px | 600 (SemiBold) | 1.2 | Button labels, form field labels, table column headers, step indicator ("Passo N de 5"), muted sheet-picker hints |
| Heading | 18px | 600 (SemiBold) | 1.2 | Each wizard step title (one per step), first-run welcome heading, About dialog app name |
| Display | 28px | 600 (SemiBold) | 1.1 | "Pronto!" on success screen, error heading on error screen; used only on step 6 screens |

Font weight integers: Regular = 400 (`QFont.Weight.Normal`), SemiBold = 600
(`QFont.Weight.DemiBold`). No other weights are used.

### Accent reserved for (explicit list — not for general interactive elements)

1. Primary action buttons (Próximo, Começar, Escolher destino e gravar, Processar outro ficheiro)
2. Drop zone border on drag-enter hover state (from neutral `#E5E5E5` → accent)
3. Keyboard focus ring (2px solid, on all focusable elements)
4. Selected state on step 1 option cards (border highlight when an option is chosen)
5. "Alterar" inline link text in step 3 column mapping
6. Application icon background

Error/Warning/Success colors are used exclusively for their named states and
are never used for decorative or neutral interactive purposes (APP-19).

## Interaction Contracts

### Step 1 — Output Type Selection

- Two `QFrame`-based option cards displayed side by side using `QHBoxLayout`.
- Each card: icon (top center, 48×48px) + heading (18px SemiBold) + description (14px Regular, word-wrap).
- Click anywhere on a card to select it; selected card gains a 2px accent-color border.
- Cards are keyboard focusable; Space/Enter selects the focused card.
- "Próximo" button is disabled until exactly one card is selected.
- "Anterior" is disabled on this step (first step).

### Step 2 — File Upload

- Drop zone: `QFrame` with `setAcceptDrops(True)`, minimum height 120px, dashed border 1px `#E5E5E5`.
- On `dragEnterEvent` with valid MIME type (file URL): border changes to 2px solid accent color.
- On `dragLeaveEvent` or `dropEvent`: border returns to dashed neutral.
- Unsupported MIME type on drop: inline `QLabel` below drop zone (not a dialog): "Formato não suportado: aceites XLSX, XLSM, XLS, ODS, CSV, TSV." Clears on next drag enter or file pick.
- "ou escolher ficheiro…" `QPushButton` opens `QFileDialog.getOpenFileName()` with extension filter.
- Once a valid file is loaded: file name displayed below the drop zone (truncated with ellipsis if > 60 chars, full path in tooltip).
- "Próximo" becomes enabled only after a valid file is loaded.

### Step 2.5 — Sheet Picker (conditional)

- Shown only when loaded Excel file has > 1 sheet (INP-10).
- `QListWidget` showing all sheet names with row count appended: `"Docentes (247 linhas)"`.
- Empty sheets listed but text color is secondary (`#878787` light / `#A3A3A3` dark) with suffix `" — folha vazia"`.
- Single selection only. "Próximo" disabled until a sheet is selected.

### Step 3 — Column Mapping

- If auto-detection succeeded: pre-populated `QLabel` per mapping with confidence indicator.
  - High confidence: green check icon + "A coluna **{name}** será usada como {role}."
  - Low confidence (ambiguous): warning icon + "A coluna **{name}** foi selecionada. Pode alterar."
  - Each mapping row has an "Alterar" link (`QPushButton` styled as inline text link in accent color).
- "Alterar" shows a `QComboBox` dropdown populated with all column names from the input.
- For elegíveis output: mecanográfico mapping row is hidden entirely (DET-07).
- Manual mode (no auto-detection): both rows start empty with active `QComboBox` dropdowns; friendly message above: "Não foi possível detetar as colunas automaticamente. Por favor, escolha quais usar:"
- "Próximo" always enabled once step is visible (user can proceed with detected or manually selected mapping).

### Processing Screen (Step 3.5 in QStackedWidget)

- Full-width indeterminate `QProgressBar` while file is loading (before row count known).
- Once first `progress_cb(current, total)` call with `total > 0`: switches to determinate bar.
- Progress label below bar: "A validar linha {current} de {total}…"
- "Cancelar" button (center-aligned below label); triggers D-01 confirmation.
- No NavBar Anterior/Próximo buttons visible during processing.
- On success: auto-advances to step 4.
- On error: auto-advances to step 6 error screen.

### Step 4 — Preview

- `QTableWidget` (read-only) showing first 50 rows of transformed output including header row.
- Rows with issues (e.g., U+FFFD removal logged as AVISO) highlighted with Warning background tint.
- Summary panel above table (fixed, not scrolled):
  - "Total de linhas: {N}"
  - "Alterações aplicadas: {M}" — with "Ver detalhes" inline link if M > 0
  - "Atenção: {K} linhas com avisos" — shown only if K > 0, in warning color with warning icon
- "Ver detalhes" toggles a `QTextEdit` (read-only, `setMaximumHeight(150)`, vertical scroll enabled) with full log content (D-03).
- "Próximo" button label overridden to "Escolher destino e gravar".

### Step 6 Success

- Large success icon (system icon `QStyle.SP_DialogApplyButton` or equivalent, 64×64px).
- "Pronto!" heading at Display size (28px SemiBold).
- Output file path in body text (truncated, full path in tooltip).
- "Abrir pasta" `QPushButton`: calls `QDesktopServices.openUrl(QUrl.fromLocalFile(dir))`.
- Summary line: "{N} linhas processadas, {M} alterações aplicadas."
- Primary button: "Processar outro ficheiro" — resets `SessionModel`, navigates QStackedWidget to index 0.
- Secondary button: "Sair" — calls `QApplication.quit()`.

### Step 6 Error

- Large error icon (system icon `QStyle.SP_MessageBoxCritical` or equivalent, 64×64px).
- "Erro no processamento" heading at Display size (28px SemiBold).
- "Foram encontrados erros que impedem a criação do ficheiro." body text.
- First 20 error lines from pipeline error, in a `QTextEdit` (read-only, max height 200px, scroll enabled).
- If more than 20 errors: "…e mais {N} erros. Ver ficheiro completo:" + path.
- "Abrir pasta" `QPushButton` pointing to the `_ERRORS_` log file location.
- Primary button: "Processar outro ficheiro".

### First-Run Welcome Dialog (APP-16)

- `QDialog` modal (not `QStackedWidget` step), shown before main window content.
- Content: app name heading + 1-paragraph PT-PT description + 4-item wizard outline.
- Single button: "Começar" — closes dialog; `QSettings` flag `first_run_shown = true` set.
- Same `QDialog` class re-opened from Ajuda → "Boas-vindas…" menu item.

### About Dialog (APP-15)

- `QDialog` (non-modal or modal — implementation choice).
- App name + version (18px SemiBold heading).
- One-line description (14px Regular).
- UMinho disclaimer verbatim from Eleitorum.md §3.5 (14px Regular, word-wrap).
- Open-source license note: "Distribuído sob a licença MIT."
- Repository link as `QLabel` with `setOpenExternalLinks(True)`.

### Menu Bar (APP-14)

| Menu | Item | Action |
|------|------|--------|
| Ficheiro | Reiniciar | Reset SessionModel → navigate to step 1 |
| Ficheiro | Sair | `QApplication.quit()` |
| Ver | Tema Escuro / Tema Claro | Toggle theme; item label reflects current state (shows opposite of current) |
| Ajuda | Boas-vindas… | Re-opens welcome QDialog |
| Ajuda | Sobre… | Opens About QDialog |

### Keyboard and Accessibility (APP-17)

- All `QPushButton`, `QListWidgetItem`, option cards, and "Alterar" links are reachable via Tab.
- Tab order matches visual left-to-right, top-to-bottom order within each step.
- Focus indicator: 2px solid accent color on focused element (set via QSS `outline` or `border` on focused pseudo-state).
- All icons in primary wizard flow paired with text labels (APP-18).
- All status states (success, warning, error) paired with a glyph in addition to color (APP-19).
- Focus indicators visible in both themes (accent differs: `#a21a1c` light / `#C73E40` dark).
