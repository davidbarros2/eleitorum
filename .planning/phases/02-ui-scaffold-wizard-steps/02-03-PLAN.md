<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS → DropZone | Files dragged from Windows Explorer; QMimeData carries `file://` URLs; only extension is trusted at this layer |
| DropZone → step_upload | Emits absolute path string; step_upload owns the next-level validation (file open, encoding) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | DropZone receives malicious file path (path traversal, ADS, unicode normalization) | mitigate | Extension whitelist check via `SUPPORTED_EXTENSIONS` runs BEFORE any I/O; the actual file is opened later by readers.py which is already covered by Phase 1 threat T-1-02-05; DropZone emits only the path string, no contents read |
| T-02-03-02 | Tampering | OptionCard receives untrusted key argument | accept | OptionCard's `key` is supplied by step_upload code, not user input; only `"caderno"` and `"elegiveis"` are passed |
| T-02-03-03 | Information Disclosure | DropZone emits absolute path containing user home directory | accept | Path is shown only inside the application UI to the same user; never written to disk or transmitted; consistent with offline-only invariant |
| T-02-03-04 | Denial of Service | Drag-enter with thousands of URLs spams paintEvent | accept | Standard Qt behavior; DropZone reads only first URL (`urls[0]`); no loops over the URL list |
</threat_model>
